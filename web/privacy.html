Confidentialité

Données traitées

Cette application auto-hébergée utilise la connexion configurée par l’administrateur pour lire les appareils, l’état des impressions, les notifications et les fichiers accessibles au compte Anycubic. Les commandes et transferts que vous demandez sont transmis à Anycubic.

Données sur cette installation

Le dossier privé peut contenir les identifiants configurés et les jetons de session. Les relevés de température et les préréglages sont enregistrés localement. Les aperçus et les références de téléchargement peuvent être gardés temporairement en mémoire.

Services externes

Le serveur échange avec Anycubic par HTTP et MQTT et utilise les liens de stockage autorisés pour les fichiers. Lorsque vous ouvrez la caméra, le navigateur se connecte à Agora pour recevoir la vidéo. L’atelier n’intègre pas d’outil de mesure d’audience.

Questions

Pour toute question sur les données conservées par cette installation, contactez son administrateur.
