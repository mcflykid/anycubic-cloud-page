# Les trois styles de l’atelier

Les [règles communes de l’atelier](regles.html) définissent les critères d’apparence des trois styles. Ce guide décrit leur utilisation.

| Style | Palette | Navigation sur ordinateur |
| --- | --- | --- |
| Par défaut | Surfaces neutres et accent vert | Barre horizontale |
| Aurore | Surfaces et accent violets | Barre horizontale |
| Laboratoire | Surfaces froides et accent bleu-vert | Menu latéral repliable |

**Réglages → Apparence** mémorise le style et le mode de couleur dans ce navigateur. Le bouton jour/nuit de l’en-tête règle le même mode. Sans choix de mode, l’atelier suit le système. Une préférence pour un style retiré revient à Par défaut.

Les palettes claire et sombre utilisent les mêmes rôles de couleur pour les textes, les cartes, les contours, l’accent et les états. La connexion et le code temporaire utilisent aussi ces palettes.

**Réglages → Apparence → Contraste** conserve un choix distinct du style et du thème. **Système** suit la préférence de contraste du navigateur. **Élevé** renforce les textes secondaires, les contours et le focus. La palette système reste prioritaire quand le navigateur impose ses couleurs.

Sur ordinateur, le trait de la navigation horizontale suit l’onglet actif. Sur téléphone, le bouton **Sections** ouvre les dix onglets. Les tuiles entrent en vague et se replient dans l’ordre inverse. Le réglage système de réduction du mouvement désactive la vague et les transitions de panneaux. Les transitions de détail de la supervision et les autres sources sont documentées dans les [références d’interaction](INTERACTION-REFERENCES.md).
